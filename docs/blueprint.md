# **App Name**: ChatWise

## Core Features:

- Social Login: Enable user registration and login via social media accounts.
- Chat Interface: Real-time chat interface for direct messaging between users.
- Secure Password Handling: Implement secure password storage and encryption.
- AI Chatbot Integration: Integrate a Google AI chatbot to analyze conversation content using a tool, and provide helpful advice.
- Firestore Integration: Store chat logs and user data in Firestore for persistent storage and retrieval.

## Style Guidelines:

- Primary color: Calm blue (#64B5F6) for a trusting and friendly atmosphere.
- Background color: Light blue-gray (#ECEFF1) to ensure readability and a soothing backdrop.
- Accent color: Warm orange (#FFB74D) to highlight interactive elements and important notifications.
- Body and headline font: 'Inter', a grotesque-style sans-serif, to provide a neutral and modern look appropriate for both headlines and body text.
- Use minimalistic, outlined icons to represent various chat actions and features.
- Design a clean and intuitive chat interface with clear message bubbles and user indicators.
- Incorporate subtle animations for message delivery and user interaction to enhance the user experience.
